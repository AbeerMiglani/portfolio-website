Dear Hiring Team,

I'm a second-year Electrical and Computer Engineering student at Shiv Nadar Institution of Eminence, and I'm excited to apply for \Company's \Role. \WhyCompany

At Manipal Hackathon 2026, I independently built Ripple, a simulator that demonstrates how a failure in a city's power, water, transit, or telecom network can cascade through interconnected infrastructure. It also recommends fixes and verifies them by rerunning the simulation. On a synthetic 120-asset city network, its top verified fix prevents up to 91\% of failures. When all-pairs shortest path became a performance bottleneck, I wrote a parallel Rust extension using PyO3 that made it 25x faster, reducing worst-case recommendation latency from 1.5\,s to 190\,ms. To ensure the Rust and Python implementations produced consistent results, I added 300 pytest tests and GitHub Actions CI.

Since July 2026, I've been building a Redis-style server in C++ using raw POSIX sockets to deepen my understanding of networking and systems programming. I designed a length-prefixed binary protocol that handles fragmented TCP reads, tested with 1,000 split requests, and implemented an event loop using non-blocking sockets to serve multiple clients on a single thread. On loopback, it handles 25,000 requests per second, with 38\,$\mu$s median and 82\,$\mu$s p99 latency across 100,000 round trips.

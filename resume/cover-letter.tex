Dear Hiring Team,

I'm a second-year Electrical and Computer Engineering student at Shiv Nadar Institution of Eminence, applying for the \Role{} at \Company. \WhyCompany

At Manipal Hackathon 2026, I built Ripple on my own: a simulator that shows how one failure in a city's power, water, transit, or telecom network spreads to the rest, and recommends fixes that it verifies by re-running the simulation. On a synthetic 120-asset city network, its top verified fix prevents up to 91\% of failures. When all-pairs shortest path became the bottleneck, I wrote a parallel Rust extension on PyO3 that made it 25x faster (33x on 2,000-node graphs) and cut worst-case recommendation latency from 1.5\,s to 190\,ms. Because the Rust and Python paths had to agree, I added 300 pytest tests and GitHub Actions CI that checks their results match.

Since July 2026, I've been building a Redis-style server in C++ on raw POSIX sockets, to understand what sits underneath the tools I use. I designed a length-prefixed binary protocol that survives fragmented TCP reads, tested with 1,000 split requests, and added an event loop over non-blocking sockets so one thread serves many clients. On loopback it handles 25,000 requests per second, at 38\,$\mu$s median and 82\,$\mu$s p99 latency over 100,000 round trips.
